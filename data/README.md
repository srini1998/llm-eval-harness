# Data

`squad_v2_sample.jsonl` is a 150-item subset of the SQuAD v2.0 dev set
(Rajpurkar, Jia & Liang, 2018, "Know What You Don't Know: Unanswerable Questions for SQuAD"),
distributed under **CC BY-SA 4.0**. This subset is shared under the same licence.
Source and checksum: `squad_v2_sample.meta.json`. `evalh sample` rebuilds it byte-for-byte.
